RELEASE MATERIALS
- Firmware identity FM-1_9980100, with update loader. No listed package has
  that exact product identity (172 entries checked 2026-11-10). Legacy broad
  patterns can match the short FM-1_998 reply; specify the full identity.
- Complete GPL-3.0-only firmware source at the release tag; score/art licences
  and upstream attribution are separate and preserved.
- fmhub.json: OCKM Studio, groove category, description, 1024-square JPEG
  under 300 KB, lavender accent. Listening preview and quick guide in bundle.
- GitHub's shared fm1-build workflow builds/signs the package from source.
  Verify the downloaded build, its attestation and checksums before publication.
- Original Puya flash (0x856014) tested. New UC25HQ80 (0xB36014) recognised
  in software but not physically tested here. Loader uses common SPI commands.

KNOWN LIMITATION
The cause of the earlier intermittent clicking/reboot is not confirmed. The
completed-job stage-wait fix addresses a reproduced host-side failure but did
not stop every hardware failure. Trace2 changed instrumentation and subsequently
ran clean; that is evidence of a clean test, not proof of a root-cause fix.
0.1.3-beta is byte-for-byte identical to the tested trace2 firmware package.
SHA256: 1714f65080b5f3adef44afa84b3287b2a06f2e3299d8f709b0d5fff0f6cc1d46
The release name, preview and documentation changed; firmware bytes did not.
The trace2 listening evidence therefore applies to this exact package.
